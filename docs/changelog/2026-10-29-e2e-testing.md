# End-to-end testing

Added Playwright and a `frontend-e2e-test` skill so agents verify UI changes in a real browser, lock important flows in with tests, and attach screenshots to PRs.

## Changes

- `@playwright/test` with [playwright.config.ts](../../playwright.config.ts): specs in `e2e/` run against `vite preview` (the production build in workerd) via `pnpm test:e2e`. A smoke spec covers the home page and the not-found page. CI runs it too.
- `@playwright/cli` for interactive checks by coding agents.
- The [frontend-e2e-test skill](../../.claude/skills/frontend-e2e-test/SKILL.md), referenced from AGENTS.md, with scripts to upload screenshots and comment on PRs.
- R2 bucket `kpixel-pr-screenshots` with a public r2.dev URL and a 30-day expiry rule.

## Decisions

- `playwright-cli` over Playwright MCP for agent-driven checks: Playwright recommends it for coding agents, since it keeps page snapshots on disk instead of in the model's context.
- Screenshots are hosted in R2 because GitHub has no API for uploading PR images. They expire, and the bucket is separate from anything the app uses.
- Canvas content is to be asserted through pixel values, not full-page screenshot diffs, which are brittle across platforms.
